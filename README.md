# Portfólio | Kauan Felix

Site pessoal de portfólio, feito para apresentar minha trajetória como desenvolvedor Full Stack em início de carreira: sobre mim, projetos, experiências, habilidades, certificados e contato.

🔗 **Acesse online:** https://kauanfelixsilva.github.io/portif-lio/

## Funcionalidades

- **Layout responsivo**, com menu ☰ para celular
- **Mini card nas habilidades:** clique em uma habilidade para ver o que sei fazer com ela
- **Destaque no menu** da seção que está na tela
- **Animações ao rolar** a página e botão de voltar ao topo
- **Cards de projetos** com as tecnologias usadas e links para o site publicado ou para a postagem no LinkedIn
- **Pré-visualização do link** ao compartilhar no WhatsApp e no LinkedIn

## Ferramentas e tecnologias utilizadas

- **HTML5**: estrutura semântica das seções
- **CSS3**: layout com Flexbox e CSS Grid, responsivo via media queries, transições e animações
- **JavaScript** (vanilla): menu de celular, mini cards das habilidades, animações ao rolar e destaque do menu
- **Google Fonts**: fonte [Poppins](https://fonts.google.com/specimen/Poppins)
- **GitHub Pages**: hospedagem do site estático
- **Git/GitHub**: versionamento de código

## Estrutura do projeto

```
portifolio/
├── index.html           # Página única com todas as seções
├── style.css            # Estilos globais e responsivos
├── js/
│   └── script.js        # Interações da página
├── curriculo.pdf        # Currículo disponível para download
└── imagens/             # Fotos, imagens de fundo, prints dos projetos e imagem de pré-visualização
```

## Seções da página

- **Sobre:** apresentação pessoal e botão de download do currículo
- **Projetos:** sistemas em PHP, JavaScript e MySQL e páginas em HTML e CSS
- **Experiências:** suporte técnico e tecnologia educacional, e o que aprendi desenvolvendo os projetos
- **Habilidades:** tecnologias que uso, com detalhes em um mini card
- **Certificados:** cursos concluídos, organizados por Front-end, Back-end e Extras
- **Contato:** e-mail, GitHub e LinkedIn
